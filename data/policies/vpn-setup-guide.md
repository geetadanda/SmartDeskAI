## 2. Before you begin

- Confirm that your device is company-managed or otherwise approved for company access.
- Install current operating-system security updates and restart if required.
- Connect to a trusted internet connection. If using public Wi-Fi, avoid sensitive activity until connected to the VPN and follow company guidance for that network.
- Have access to your company sign-in and approved MFA method. Never share passwords, one-time codes, or recovery codes with IT or anyone else.
- Save your work. Installation or network changes may require a restart.
- If you have an existing VPN profile, do not delete or alter it without IT direction.

## 3. Windows installation and connection

1. Open the company software portal or managed software catalog: **[IT: portal name/link]**.
2. Find the supported VPN client listed for Windows in Section 1. Check that the publisher and product match the IT listing.
3. Select **Install** and approve only the prompts generated by the company-managed installer. If the device requests administrator credentials you do not have, stop and submit an IT request.
4. Restart if prompted. Open the VPN client from the Start menu.
5. If the profile was not provisioned automatically, choose the IT-provided setup option and enter or import only the approved configuration from **[IT: secure configuration instructions]**. Do not guess the gateway or import a profile from an untrusted source.
6. Select the company profile and choose **Connect**. Sign in through the company identity page and complete MFA when prompted.
7. Confirm that the client reports **Connected**. Test access to the company resource you need.
8. When finished, disconnect from the VPN if your role or IT instructions require it. Keep the client installed and updated unless IT directs otherwise.

## 4. macOS installation and connection

1. Open the company software portal or managed software catalog: **[IT: portal name/link]**.
2. Install the supported macOS client shown in Section 1. If IT directs you to a vendor installer, use only the verified link published by IT.
3. Open the client from **Applications**. Approve system-extension, network-extension, or VPN configuration prompts only when they identify the expected company client and publisher. If a prompt is unfamiliar, cancel and contact IT.
4. If the company profile was not provisioned automatically, use **[IT: secure configuration instructions]** to add the approved profile. Do not enter an unverified server address.
5. Select the company profile and click **Connect**. Complete company sign-in and MFA.
6. If macOS asks to add a VPN configuration or allow a network extension, verify the client and profile details, then approve as directed by IT. You may need to enter your Mac's local administrator password; never provide it to support personnel.
7. Confirm the client reports **Connected** and test the required company resource.
8. Disconnect when finished if instructed. Do not remove the profile or security controls without IT approval.

## 5. Linux installation and connection

Linux support is limited to the distributions and releases listed in Section 1. If your distribution is not listed, contact IT for an approved alternative; do not adapt instructions for another distribution or install an unofficial client.

1. Confirm your distribution and version are supported. Open the company-managed software catalog or repository instructions at **[IT: Linux setup page]**.
2. Install the client using the documented package manager commands or managed deployment instructions provided by IT. Use only the package source and signing-key process documented there.
3. If the device requests elevated privileges, review the command against the official IT instructions. Do not run commands copied from an unverified message or website.
4. Launch the VPN client using the documented desktop application or command supplied by IT.
5. Import or create the company profile only as described in **[IT: secure Linux configuration instructions]**. Keep configuration files private and do not post them in tickets or chat.
6. Connect to the company profile, complete company sign-in and MFA, and wait for the client to report a successful connection.
7. Test access to the company resource required for your work. If connection fails, record the exact error and client version.
8. Disconnect using the documented client controls. Do not disable the system firewall or change routes, DNS, or security settings to force a connection.

## 6. Common errors and first checks

| Symptom or message | Checks employees can safely perform | If it continues |
|---|---|---|
| Sign-in rejected or authentication failed | Confirm you are using your company account and the official sign-in page. Check for an account lock notice. Do not repeatedly guess passwords. | Contact the service desk for account assistance. Never send your password or MFA code. |
| MFA prompt not received or unexpected prompt appears | Check that your enrolled device has connectivity. Deny any prompt you did not initiate. | Contact IT using the escalation details below to verify or re-enroll your factor. Report repeated unexpected prompts immediately. |
| Server/gateway unavailable or connection times out | Check internet access by opening a permitted public site; verify the company VPN profile is selected; retry once after a short wait. | Send IT the timestamp, network type (home/public), client version, and exact error. |
| Client or profile not found | Confirm the client is from the approved software portal and your device has completed company enrollment. | Ask IT to verify the supported client and provision the profile. Do not download a replacement from an unapproved source. |
| Certificate, trust, or security warning | Stop. Do not bypass the warning, install an unknown certificate, or accept an unexpected profile. | Contact IT and include a screenshot with personal or confidential information removed. |
| Connected, but company resources are unavailable | Confirm the resource is one you are authorized to access; disconnect and reconnect once if instructed by IT. | Provide the resource name, time, and whether other company services work. Do not change DNS, firewall, or routing settings. |
| Slow connection | Check whether other devices or applications are using substantial bandwidth; move to a stable trusted connection if possible. | Tell IT when the issue occurs and which approved resources are affected. |
| Client installation requires administrator rights | Stop if you do not have authorized administrator access. | Submit a software-installation request so IT can deploy the approved client. |

Do not disable endpoint protection, change firewall settings, install certificates, edit routes or DNS, or use another VPN to work around an error. Contact IT instead.
